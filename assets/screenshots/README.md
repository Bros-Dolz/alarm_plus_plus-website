# App screenshots

The homepage feature sections reference these six files by exact name. They are
1080 × 2400 PNGs taken straight from the device — no cropping needed, the site
frames them.

| File | Screen |
|---|---|
| `ringing.png` | The ring screen — time, label, Snooze 10 min, Dismiss |
| `shuffle.png` | Shuffle playlist — entries, Random, Play the videos' sound |
| `wake-me-with.png` | Edit alarm → the "Wake me with" sheet, Sound tab |
| `alarms.png` | Alarms list — Next alarm card and alarm rows |
| `world-clock.png` | Clock tab — local time and pinned cities |
| `timer.png` | Timer — depleting ring, Cancel / +1:00 / Pause |

If you replace one, keep the filename and keep the aspect ratio at 9:20
(1080 × 2400). The `width`/`height` attributes in `index.html` are set to those
numbers so the page reserves the right space before the image loads; change them
together if a screenshot is ever a different size.
